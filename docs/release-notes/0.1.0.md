First release of the Rust client for the Vynull 0.6.0 daemon: a web client and a desktop client from one code base.

**Screens:** Players (decks, waveform stack, phrases, master and sync), Library (search, tags, playlists, queue,
sorting, drag to reorder a playlist, import and export), a track drawer (zoom waveform with the beat grid, cues,
tempo and grid editing, metadata), Tags, Settings, Diag and Overlay.

**Packages**

| Platform | Files |
|---|---|
| Linux x86_64 | `.deb`, `.rpm`, `.AppImage`, Flatpak bundle |
| Linux aarch64 | `.deb`, `.rpm`, Flatpak bundle |
| macOS, Apple silicon | `.dmg` |
| Windows x86_64 | `.msi`, `-setup.exe` |
| Browser | `vynull-web-0.1.0.zip` |

`SHA256SUMS` lists every file. **Nothing is signed or notarised**: macOS and Windows will warn.

**Known limits:** tested in headless Firefox and Chrome against test daemons; the desktop window has been run on
Linux only; Safari and iPhone are untested; the daemon has no authentication, so use a trusted LAN. See the README.
