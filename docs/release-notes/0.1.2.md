Features and fixes after 0.1.1.

**New**

- **Settings is a gear** at the top right, beside the connection button. **Diag** and **Overlay** are now sections
  of Settings instead of tabs (their addresses `#/diag` and `#/overlay` still work).
- **Accent color** (Settings, WEB UI): six presets or any color from a wheel, with a brightness slider and a hex
  field. It applies at once and is remembered.
- **No daemon yet?** The connection screen explains that the app needs the separate Vynull daemon (Linux only) and
  links to its page and releases.
- **Playlist folders collapse and expand**, and folders, playlists and smart playlists have icons. Closed folders are
  remembered.
- **Import:** type the path of the file on the daemon's computer (the daemon's file picker only lists folders and
  audio files, so an XML or database file could never be picked).

**Fixed**

- The library list looked empty after changing playlist or search until you scrolled.
- **Search keys:** Enter keeps what you typed; Down, then Enter, picks the first suggestion.

**Packages:** same set as 0.1.1, with `SHA256SUMS` (`vynull-web-0.1.2.zip` for browsers). **Nothing is signed or
notarised.**

**Known limits:** tried by hand on Windows and Linux; macOS (the `.dmg` has never been opened), Safari and iPhone
are untested; the daemon has no authentication, so use a trusted LAN. See the README.
