Fixes after the first release. Use this one instead of 0.1.0.

**Fixed**

- **A track whose key is not a plain Camelot key could take the whole library down.** A key ending in a
  multi-byte character, such as `F♯` or `9♭`, made the client panic, and the library list stopped rendering.
- **The stream overlay preview opened your web browser instead of showing in the window** in the desktop
  client (every address a desktop webview loads is sent to the system browser). The preview is now the daemon's
  own `/overlay` page shown in the window.
- **Desktop client: the live deck state could freeze.** If the daemon's host went away without closing the
  connection (sleep, a Wi-Fi change), the window stayed on LIVE with frozen decks and never reconnected. A link
  that is silent for 10 seconds is now dropped and reopened.
- **Desktop client: a seek or a play asked while a track was still loading was lost**, so switching the WAV
  option mid-track, or clicking a cue right after opening a track, restarted from 0:00 or did nothing.
- **Desktop client: audio downloads gave up after 30 seconds**, which a long or transcoded track on a slow link
  can exceed. The limit is now 10 minutes.
- **Search suggestions** no longer crash on some non-Latin text (for example Korean) and no longer highlight the
  wrong part of text with combining accents.
- **Settings:** an edit keeps the JSON type of the setting (a number stays a number, a boolean a boolean).
- **The "not on a private network" banner** no longer shows for a private IPv6 address.
- Library sort and single-track edits do less work (a one-row search-index update takes about 1.4 ms instead of
  9.6 ms for 4,000 tracks, measured natively).

**Changed**

- Settings opens on WEB UI.
- The overlay preview is the daemon's own page, so it matches what a streaming program shows.
- The Windows installer (`-setup.exe`) is about 5.6 MB because it carries the small WebView2 bootstrapper, not
  the 190 MB offline runtime installer, so a PC without WebView2 and without internet cannot install it. The
  0.1.0 release page already had this file, swapped in by hand after the tag; 0.1.1 builds it from the tagged source.

**Packages:** same set as 0.1.0 (Linux x86_64 `.deb`, `.rpm`, `.AppImage`, Flatpak; Linux aarch64 `.deb`, `.rpm`,
Flatpak; macOS `.dmg`; Windows `.msi` and `-setup.exe`; `vynull-web-0.1.1.zip`), with `SHA256SUMS`. **Nothing is
signed or notarised.**

**Known limits:** tried by hand on Windows and Linux; macOS (the `.dmg` has never been opened), Safari and iPhone
are untested; the daemon has no authentication, so use a trusted LAN. See the README.
