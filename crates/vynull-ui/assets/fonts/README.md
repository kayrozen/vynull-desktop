# Bundled fonts

Subsets of Roboto (variable weight, Latin and Latin Extended) and Cousine
(Regular and Bold, Latin), taken from the Google Fonts files used by the design
mockup. Both families are licensed under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0). They are embedded so the client
looks the same on a booth network with no internet access.

Other scripts (Cyrillic, Greek, Vietnamese, ...) are not included: text in
those scripts falls back to the system fonts.
